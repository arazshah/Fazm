# فازم — fazm.ir

فازم یک همراه کوتاه‌گفت‌وگو برای پیدا کردن نامِ حال فعلی است. کاربر آزادانه حرف می‌زند، مدل با سؤال‌های کوتاه فاز را روی چند محور برآورد می‌کند، چند پیشنهاد کوچک می‌دهد و یک لینک عمومی می‌سازد که **فقط تصویر انتزاعیِ فاز** را نمایش می‌دهد.

## اجرای محلی

نیازمندی: Node.js 22 یا جدیدتر.

```bash
cp .env.example .env
# مقادیر .env را تنظیم کنید، سپس:
npm start
```

سایت روی `http://localhost:3000` اجرا می‌شود. برای تست: `npm test`.

## PWA

فازم یک Progressive Web App است: `manifest.json` و `service-worker.js` در `public/` باعث می‌شوند از کروم اندروید بشود آن را «افزودن به صفحهٔ اصلی» کرد و مثل یک اپ نصب‌شده باز شود. سرویس‌ورکر فقط پوستهٔ استاتیک (HTML/CSS/JS/آیکون‌ها) را کش می‌کند؛ مسیرهای `/api/*` و `/f/*` همیشه از شبکه خوانده می‌شوند تا گفت‌وگو و تصاویر خصوصی/تازه بمانند.

## معماری MVP

- سرور Node بدون وابستگی خارجی؛ API key هرگز به مرورگر نمی‌رود.
- AvalAI از API سازگار با OpenAI برای chat و image استفاده می‌کند.
- گفت‌وگو و وضعیت در `data/db.json` و تصاویر در `data/images` ذخیره می‌شوند.
- هر نشست یک secret مالک و یک slug عمومیِ جدا دارد.
- تصویر SVG کم‌هزینه همیشه موجود است و پس از جمع‌بندی گفت‌وگو، تصویر مفهومی AI به‌طور خودکار ساخته می‌شود.
- صفحه عمومی `fazm.ir/f/:slug` فقط تصویر دارد و `noindex` است.
- هر پاسخ یک نقطهٔ تاریخی با زمان، شدت، انرژی و تصویر خودش می‌سازد؛ «گفت‌وگوی تازه» این تاریخچه و لینک ثابت را حفظ می‌کند.
- پس از حداکثر چهار پاسخ، مرحله جمع‌بندی می‌شود و تصویر AI به‌طور خودکار ساخته و لینک آن داخل گفت‌وگو اعلام می‌شود.
- نشست مهمان در همان مرورگر خودکار حفظ می‌شود. یک لینک بازگشت خصوصی مبتنی بر URL fragment هم برای بازیابی روی دستگاه دیگر وجود دارد؛ fragment به سرور ارسال نمی‌شود و باید مانند رمز خصوصی نگهداری شود.
- هر کارت «رد فازها» قابل بازشدن است و حرف همان لحظه، تحلیل مدل، شش شاخص و سه پیشنهاد را مستقل از متن گفت‌وگوی جاری نگه می‌دارد.
- تصویر AI با یک استعارهٔ بصری و صحنهٔ مفهومی تولید می‌شود؛ گرادیان خالی، لکه‌های انتزاعی، آیکون و متن در prompt منع شده‌اند.

این ذخیره‌سازی برای یک سرور کوچک مناسب است، نه چند replica. قبل از رشد، آن را با PostgreSQL و object storage جایگزین کنید.

## تعریف محصول

### وعدهٔ اصلی

«لازم نیست بدانی چه حسی داری؛ چند دقیقه حرف بزن، اسم فازت را پیدا کن و بدون توضیح اضافه نشانش بده.»

### حلقهٔ اصلی

1. شروع بدون ثبت‌نام و بدون درخواست نام.
2. یک سؤال باز، سپس حداکثر یک سؤال در هر نوبت.
3. برآورد پیوسته روی هیجان، شدت، انرژی، خوشایندی و اطمینان.
4. نمایش نام خاص فاز و حداکثر سه اقدام کوچک.
5. ساخت/به‌روزرسانی تصویر روی همان لینک ثابت.
6. بازگشت کاربر در زمان دیگر و دیدن تغییر فاز.

### چیزهایی که بهتر است بعداً اضافه شوند

اولویت بالا:

- تاریخچهٔ خصوصی به شکل تقویم رنگی، با امکان حذف کامل و خروجی گرفتن.
- کنترل اشتباه مدل: دکمه‌های «دقیق بود / نبود» و «کلمه‌اش را عوض کن».
- حالت مهمان با انقضای خودکار ۷ یا ۳۰ روزه و حساب اختیاری برای ماندگاری.
- چرخاندن یا غیرفعال‌کردن لینک عمومی و امکان تعیین تاریخ انقضا.
- صف تولید تصویر، object storage و محدودیت هزینه برای هر کاربر/IP.
- سیاست حریم خصوصی فارسی، رضایت روشن، رمزنگاری، retention محدود و حذف لاگ‌های حساس.
- مسیر بحرانِ تست‌شده توسط متخصص؛ مدل نباید تنها لایهٔ تشخیص خطر باشد.

اولویت متوسط:

- ورودی صوتی برای وقتی نوشتن سخت است.
- «دایرهٔ نزدیکان»: انتخاب اینکه تصویر برای چه کسی و تا چه زمانی دیده شود.
- فاز دونفره برای زوج/دوست: هر نفر فقط تصویری را که رضایت داده به اشتراک بگذارد.
- شخصی‌سازی سبک تصویر (مینیمال، طبیعت، فضایی، ایرانی) بدون چهرهٔ قابل‌شناسایی.
- یادآوری اختیاری و کم‌فشار؛ نه streak و نه احساس گناه.
- تحلیل روند فقط با زبان احتمالی: «به نظر می‌رسد»، نه «تو افسردگی داری».

### چیزهایی که نباید فعلاً اضافه شوند

- فید عمومی و مقایسهٔ حال آدم‌ها؛ حریم خصوصی و نمایش‌گری را بدتر می‌کند.
- امتیاز «سلامت روان» یا برچسب بیماری.
- تولید خودکار تصویر بعد از هر پیام؛ کند و پرهزینه است.
- ثبت‌نام اجباری در ورود اول.
- بیش از سه پیشنهاد؛ در حال خستگی یا فشار تبدیل به بار شناختی می‌شود.

## قبل از انتشار روی fazm.ir

- `PUBLIC_BASE_URL=https://fazm.ir` و secretهای محیط production را تنظیم کنید.
- HTTPS، reverse proxy، backup و مانیتور خطا را در محیط production فعال کنید؛ محدودیت درخواست در خود برنامه نیز برقرار است.
- `data/` را روی volume پایدار قرار دهید و دسترسی فایل‌ها را محدود کنید.
- متن بحران و سیاست نگهداری داده را با روان‌شناس و مشاور حقوقی بازبینی کنید.
- روی موبایل واقعی، اینترنت کند و پاسخ‌های مبهم/طعنه‌آمیز فارسی تست کاربری انجام دهید.
